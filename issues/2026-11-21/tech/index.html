11月19日官方开发者公告

网页交给代理前，Perplexity 新增一层判断分数

开发者可以先问一个是非问题，再决定是否让代理读取某张网页。Perplexity 在11月19日官方开发者论坛宣布，Context API 已接入 Decider：针对 Context 抓取的网页提问后，它为每页返回0到1的分数。公告把在代理读取前检查提示注入列为一种用途。官方公告 ↗

这层判断位于网页获取和后续使用之间。分数是模型对问题的判断，不能直接当成网页安全证书。公告没有提供足以承诺拦截所有攻击的独立结果；能请求一次检查，不代表代理已免于攻击。本刊未调用该 API，不报告识别率或额外收费。
