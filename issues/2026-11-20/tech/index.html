Windows 代理隔离更新，三种功能处于不同开放阶段

把任务交给能读写文件的代理，企业还要决定它能接触哪些文件和网络。微软 11 月 17 日的 Windows 公告介绍了 MXC 的三项更新：进程容器改进处于预览；用于观察代理正常行为的 learning 与 permissive 模式已正式可用；本地 Micro VM 仍属实验功能。三者不能合并写成同一项“全面上线”。公告把隔离、身份区分和管理列为不同层次；实际部署仍需核对设备、代理版本及策略。这里依据微软说明解释开放阶段，不把厂商的安全主张当作本刊验证结论。微软原文 ↗
