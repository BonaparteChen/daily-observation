# 09｜要点拆解

本卡整体为新增文体（v3 扩展，2026-11-24）。把一篇长内容拆成普通读者约 1 分钟能读完的要点短稿。沿用 [00 共同文风](00-common-style.md) 的写作与交稿规则；00 中原六卡的量表沿革不适用于本卡，09 的判据以下表为准。

## 适用判定

「值得分享／做成摘要」类点单默认用本卡：围绕同一篇已发布的长文、一支视频或一份报告，忠实拆解并重排原有要点，不引入原文之外的新事实。靠一件新动作推进阅读，用 [02 短资讯](02-short-news.md)；靠同一把尺挑选多个对象，用 [06 清单](06-list.md)。不因用了编号就归清单，也不把多份独立材料拼成一篇摘要。

## 输入材料门槛

- 一手材料全文可读；视频须取得完整字幕或转写，并能对回原视频时间戳。有图表或附注承担关键论证的，须能读到相应图表和口径。确认题名、作者或发布方、原文 URL、发布日期及所用版本；日期确实查不到就如实标「未核实」，不拿抓取日期冒充发布日期。
- 通读后能找出至少三条互不重复、有原文位置支撑的要点。段落、章节、页码、表图号或时间戳应足以定位；归清作者判断、受访者说法及原文的不确定性。原文转引可以按原文位置转述，但不当成已独立核实。
- 只有标题、简介、片段或不完整字幕时先补采；全文仍不齐，或通读后仍凑不出三条有据要点，标 `BLOCKED` 并列缺件及受影响的要点，不凭摘要、印象或外部消息补写。见 [07 全局反例卡](07-failure-cases.md)。

## 选题指引

先问「读者只留一分钟，最该带走哪几条？」优先选能回答同一个日常问题、相互不重复的内容。影响理解或适用范围的限制跟着对应结论走；若结论脱离限制就会变义，不能为省字而删掉限制。

## 结构骨架

1. 标题给出具体对象和阅读抓手；正文用**一句话总览**交代原文讲了什么、为什么值得读者看，从具体人物、场景或日常问题切入。标题下或首节保留一眼可达的主来源（来源名、原文链接、日期），不代替第三块。
2. **要点清单 3–7 条**：按对读者的重要性重排，不照抄原文顺序；每条一句结论打头，再用 1–2 句给证据、解释或必要限制。每条就近标原文位置，或用能映射到具体位置的信源标号。
3. **来源链接与日期**：列原文题名、作者或发布方、原文 URL 和发布日期；有不同版本时注明所用版本，使用标号时逐一对应来源与位置。
4. **给读者的想法与建议**：另起同名一节，给基于要点的具体判断、可做的小动作或避坑提醒，明示是编辑提炼，不写成原文主张。此节必须保留、放在全文最后；不在后面再放来源、总结或核稿备注。自查证据另交，见 [00](00-common-style.md)。

## 写作手法清单

- 标题｜只承诺正文确实交付的内容；标题含数量就逐条对数；原文里的「可能」「计划」「在某范围内」不得压没。
- 开头｜先给读者认得的具体场景或问题，在同一句说清原文主题和阅读收益；不从文件编号、报告名或数据堆起笔。
- 信源｜先定原文版本再摘取；作者结论、推测、被引者说法分别归属。引语和数字可回查，范围、时间、样本、单位、分母按需保留。
- 视角语气｜结论句是要点的领句，不等于把被引说法或推测升级为结论。专业术语、制度名词、缩写首现紧跟一句不靠其他术语的白话解释；在独立条目中首现就地解释。
- 节奏｜最有用的先写，同义项合并。关键数字换成每人、每次、常见时段等日常尺度，保留原值和口径；换算标明依据和必要算式，不易换算就白话说明原口径。没有数字时说清具体情境、动作或限制，不硬造数字。
- 结尾｜给读者下一次遇到同类情境可以问什么、做什么；条件不明就把建议写成自查问题，不拿编辑提炼补新事实。
- 图说｜不要求配图。用到原文图表就贴对应要点，标原图来源、版本和位置；保留单位与口径，不让示意图替代证据。

## 示例注入

- 模拟报告《社区图书馆自助还书试点记录》（以下为虚构结构示意，非事实来源，不作黄金题）：假定原文依序为 §1「仅在甲馆试行」；§2「开放时段内可在机器上还书，不必找柜台人员」；§3「馆员推测可能缩短排队时间，报告没有计时」。
- 标题「不找柜台也能还书？读懂甲馆自助还书试点」 → **总览**「想还书又不想去柜台，这份试点记录交代了哪家馆、什么时候能用机器还书，以及省不省排队时间还有什么没弄清。」 → **要点 1／先给操作**「开放时段内可以用机器还书。不必先找柜台人员。」〔§2〕 → **要点 2／紧跟范围**「这项做法只在甲馆试行。不能把这一入口当成其他分馆也有。」〔§1〕 → **要点 3／保留推测**「是否少排队还不知道。馆员说可能缩短等待，但报告没有计时。」〔§3〕 → **来源链接与日期**（标注位：正式稿填原文链接及发布日期，标题下同步给主来源入口；模拟例无实际链接或发布日期） → **给读者的想法与建议**（编辑建议）「如果你打算用机器还书，出门前先查自己要去的分馆有没有这一入口；不要把可能省时当成行程保证。」

## 打分量表

8 项 × 0/1/2 分，满分 16 分，≥13 分才过分数线；KP1、KP2、KP3 任一为 0 则整稿不合格，第 8 项不设事实闸。关键事实、数字或归属无据或有误，即使出现在其他项，也须把对应事实项置 0。见 [00](00-common-style.md)。建议节缺失或未在全文最后，属于结构未交齐，即使过分数线也须补正后再交；不另设事实闸。

| 项 | 0 缺失/错误 | 1 勉强 | 2 到位 |
|---|---|---|---|
| KP1 要点忠实度（事实闸） | 添入原文之外的事实或观点，改动关键数字或范围，或把原文的推测、引述写成原文结论 | 核心结论、口径与归属均忠于原文，个别非关键语气或细节交代不够清楚 | 逐条保留原文结论、口径、适用条件和确定度；作者判断、推测、被引者说法分清，不掺外来事实或观点 |
| KP2 总览与标题兑现（事实闸） | 缺标题或一句话总览，或标题、总览承诺的核心对象、范围、结论、数量或确定度在正文不兑现 | 标题和一句话总览与正文一致，总览说清原文讲什么，但阅读收益较泛 | 标题具体且兑现；一句话总览讲清原文讲什么、为什么值得读者看，与正文范围、承诺数量（如有）及确定度一致 |
| KP3 信源可核（事实闸） | 一手全文未核或无可用原文链接，或任一要点、关键数字或归属不能回查或指错出处 | 全文已核，原文链接和每条定位均可回查；非关键版本或归档信息不齐，或发布日期未核实但已如实标注 | 全文已核，来源名、原文链接和发布日期齐备，所用版本明确；每条就近标位置或可回指具体位置的信源标号，关键数字和归属能定位 |
| KP4 选点与排序 | 照原文顺序逐段缩写而无读者优先级，或用重复要点挤掉核心信息 | 主次大体可辨，但个别条目位置或取舍仍不利于读者理解 | 按对读者的重要性重排，先给最有用的要点；条目不重复，必要限制跟着对应结论 |
| KP5 条目骨架 | 不是 3–7 条，或多数条目没有领句、没有展开 | 有 3–7 条且多数可独读，但个别未以结论领句或展开不合句数 | 有 3–7 条，每条一句结论打头，再用 1–2 句展开，一个条目只推进一个要点 |
| KP6 一分钟节奏 | 有大段转述、背景或重复，读者难以在约一分钟内读完 | 基本可扫读，仍有可删的背景、铺垫或重复说明 | 普通读者约一分钟能读完；删掉不影响理解的背景和重复，必要证据与限制仍在 |
| KP7 建议分轨与压尾 | 缺「给读者的想法与建议」、未放在全文最后，或把编辑建议冒作原文判断 | 同名建议节在来源之后、全文最后，且与原文分开；建议较泛或未指到可用场景 | 来源后以「给读者的想法与建议」压尾；明示编辑提炼，建议紧扣要点并给具体判断、动作或避坑提醒，不引入原文之外的新事实 |
| KP8 读者可理解性（v3 扩展，2026-11-24） | 下列三条至多满足一条 | 下列三条满足两条 | ① 一句话总览先给原文可核的人物、具体场景或读者日常问题，不以文书、报表起笔；② 专业术语、制度名词、缩写首现均紧跟一句不含其他术语的白话解释（无则满足）；③ 把关键数字或限制放到日常尺度，换算保留原值、口径和可复算依据；无数字时说清关键非数字信息对读者的具体意义，不添数字 |

## 本文体反例卡

- 读了简介就写「视频里说」｜没有完整字幕／转写却交付全片摘要｜先补齐原视频和完整字幕或转写；补不到就标 `BLOCKED`。
- 试探变结论｜原文是「作者推测」或「受访者称」，标题却写「报告证实」｜在同一处恢复说话人、原有语气和适用限制；对应修改标题及总览。
- 按页码压缩或用外部信息填条数｜读完开头仍不知最有用的是什么，或找不到某条的原文依据｜按读者重要性重排，合并同义项，撤掉超出原文的句子；不足三条不交成稿。
- 来源或备注压过建议｜建议夹进要点、被写成作者意见，或后面还挂来源和自查｜把可核事实留在要点，来源放建议前，另起同名建议节收尾，自查另交。
