# QDaily 编辑训练｜第三步 skill 系列

用稿件靠什么推进阅读来选卡；默认先读共同文风，再叠加一张文体卡。此系列是基于样本编成的训练工具，不是《好奇心日报》内部刊规。

| 文件 | 一句话用途 |
|---|---|
| [00-common-style.md](00-common-style.md) | 共用标题语气、提问、证据归属、未确认处理及打分闸门。 |
| [01-long-form.md](01-long-form.md) | 两类独立证据对读，让同一主问逐步改观；另分访谈与书评门槛。 |
| [02-short-news.md](02-short-news.md) | 围绕唯一一件新事，交代适用范围、确定度和读者后果。 |
| [03-digest.md](03-digest.md) | 同一新闻窗的独立更新按不同栏目分流，头条和末条各司其职。 |
| [04-photo-essay.md](04-photo-essay.md) | 用图文单元带读者进入新闻，或用连续图表拆解同一问题。 |
| [05-data-story.md](05-data-story.md) | 找到可辩护分母和基线，以一项量化比较检验直觉。 |
| [06-list.md](06-list.md) | 给定选择池和同一筛尺，让多项选择各自可跳读、可使用。 |
| [07-failure-cases.md](07-failure-cases.md) | 四个真实生产事故对应的全局红线：归属、材料、权限和异构终审。 |
| [08-golden-tests.md](08-golden-tests.md) | 固定六道历史材料题，逐项连接文体量表，供试产与回归。 |
| [README.md](README.md) | 本索引与生效关系、证据边界。 |

用法：选卡 → 验材料门槛 → 按证据列段序 → 参考结构示例 → 对照反例和八项量表自查 → 交异构模型作独立终审。（v3，2026-11-24，据校准案例 1）作者不代填正式结论。比例是样本量或编辑起配，不是硬阈值；评分阈值、BLOCKED 与回归规程属于本项目的执行口径。

v3 说明（v3，2026-11-24，据校准案例 1）：00 增加普通人的读者入口和术语首现白话解释，01 落实读者入口段，05 要求核心数字有可复算的日常尺度翻译。六卡原第 1–7 项编号和判据不变；各加第 8 项「读者可理解性」（L8/S8/D8/P8/N8/C8），每项 0/1/2 分，满分 16 分，≥13 分才过分数线；任一事实闸为 0 仍整稿不合格，第 8 项不设事实闸。08 仅同步评分框架，固定题面的各项要求不变。

与旧训练包 `qdaily-style-pack.md` 的关系：本系列为准。旧包保留为长文历史参考；冲突条目以本系列为准，不修改旧包，也不修改 editor 的 SOUL.md。本步交付文件，不做运行时集成；集成由总调度验收后执行。

证据与边界：[第二步拆解稿](../../delivered/qdaily-style-breakdown-step2.md)，样本核查 2026-11-24（UTC+08:00，细时见各卡）。六卡原七项沿用拆解原序，新增项来自本项目校准，不是原刊规则（v3，2026-11-24，据校准案例 1）；样本注入只用结构转述，不复制原文段落；未立复更后习惯、图像美术标准、全刊固定配比或字数。黄金题的原材料是测试输入，不作补充文风规则；生产红线仅据本次任务给出的事故记录。
