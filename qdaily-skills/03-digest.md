# 03｜资讯汇编

叠加 [00 共同文风](00-common-style.md)。标题挑头条，正文靠栏目和独立条目分流。

## 适用判定

同一新闻窗口内有多件可独立成立的新事，读者要快速扫读。仅一件转短资讯；同一事件的多方回应放同一条；若是用同一筛选尺挑对象而不是追新闻，转清单；画面才是每条的入口则转图说。

## 输入材料门槛

明确窗口及假期/周末例外；至少两条独立新消息。逐条备可读的完整原公告、通报、名单或具名报道等出处，能指出新动作、日期、状态；使用数字时查地区、时段、币种、指标与估值/票房口径；涉及当事方回应注明来源及状态。仅标题、重复转发、传闻或陈年消息不计入门槛。逐条补采，缺证条目撤下；若达不到两条且不能转型，`BLOCKED`。图非必需，有图才核原件与署名。

## 选题指引

选改变规则、确定档期、给出新数字或有效回应的条目；商业可跨公司、政策和市场，娱乐可并置作品、档期、片权、人事与数字。不用无新增的重复项凑栏，不强行找一条宏观趋势串全部消息。

## 结构骨架

栏目名＋2–3 个具体头条 → 一句窗口与筛选承诺 → 焦点段群 → 按不同收录原则分区 → 用末条或日程结束。标题不等于正文排序。

- 单条：短题/加粗首句 → 动作、状态和出处 → 必要数据或一项背景；重点条可扩几段辨析。
- 商业早例可用导语→公司→东八区→其他新闻；[6820](https://www.qdaily.org/articles/6820/) 约 3/29/20/48%。晚例可用数篇小解释→短讯串→财报日程。
- 娱乐可用新鲜事→人物→数字（样本正文约 57–79%／12–25%／7–17%），也可用焦点→其他板块→单列讣告。占比是样本参照，不是配额；不为凑齐旧栏目硬补料。

## 写作手法清单

- 标题｜并列具体事件/数字；「据」「可能」「否认」不能改写为已确认。
- 开头｜很快交代时间窗和入选理由，引导读者进入首栏。
- 信源｜逐条就地给来源；交易、政策、奖项尽量查文件、通报或名单；同一件的报道、回应与未回应分开。
- 视角语气｜导航词可口语；并购、诉讼、死亡等把状态写准确，不强套趋势。
- 节奏｜换条就明确换主体；复杂焦点多给段落，末栏用较短单位。
- 结尾｜有用的最后一条、日程或具名出处的讣告即可，无独立总结义务。
- 图说｜剧照/海报紧贴条目、标作品及来源；素材署名不是对档期或票房的核实。

## 示例注入

- [64063｜大公司头条](https://www.qdaily.org/articles/64063/)：导语定任务 → 车辆购置税条解释计税变化 → 深圳个税条校验算例/留人群边界 → 华为相关条区分制订标准与生产产品 → 短讯串分流 → 本周财报给日程。专标题的三焦点各有多段，尾栏虽总量大仍是短条。
- [64072｜今日娱乐](https://www.qdaily.org/articles/64072/)：首栏把戛纳赛果拉成焦点 → 定档/预告等换到另一用途 → 动态/数字各自汇拢 → 具名出处的讣告作末条，同时兑现第二个标题点。分组约 25/34/20/14/6%。

## 打分量表

16 分制，≥13 分；第 8 项不设事实闸（v3，2026-11-24，据校准案例 1）。任一事实闸为 0 则整稿不合格。见 00。

| 项 | 0 缺失/错误 | 1 勉强 | 2 到位 |
|---|---|---|---|
| D1 新闻窗与独立性 | 少于两条独立新事，或无明确窗口且混旧闻 | 两条以上，窗口可推知但未写明/漏补辑提示 | 明示窗口及例外，至少两条本窗口独立更新 |
| D2 标题兑现（事实闸） | 承诺的条目不见或关键状态/数字改错 | 都找得到，标题提示较含混但未改事实 | 每个标题点可定位，核实程度与正文一致 |
| D3 分栏原则 | 不能说出各栏差异，或一事拆作两条凑数 | 多数分组可辨，边界有重复/用途不清 | 每栏有不同纳入理由，同事回应放一条 |
| D4 单条独立可读 | 离开上一条就不知道主体或动作 | 大多独读，个别缺必要前情 | 每条有主体、动作、来源/状态和必要背景 |
| D5 来源及口径（事实闸） | 关键出处/数字错挂、无据或混并不同口径 | 主源和关键口径可回查，少数次要范围欠清 | 逐条标文件/自报/转述/未回应，关键数字时段、币种、地区及指标可核 |
| D6 轻重与收尾 | 等量堆砌且尾部凑栏/硬总结 | 有主次，末尾有实质但编排拖沓 | 焦点、短条有粒度差，末条用事实/日程/讣告收住 |
| D7 图源与对应（事实闸） | 使用失效、无源、错对象图片或把配图当消息出处 | 图源清楚可开，摆位不够就地 | 图与条贴合、有可核署名，图源与新闻来源分开；无必需图不添 |
| D8 读者可理解性（v3，2026-11-24，据校准案例 1） | 下列三条至多满足一条 | 下列三条满足两条 | ① 导语先用一条焦点消息里的具体人、场景或日常问题带入，再交代新闻窗，不以文书、报表起笔，也不硬串其他条；② 各条独读时，专业术语、制度名词、缩写首现均紧跟一句不含其他术语的白话解释（无则满足）；③ 各条就地给关键数字或信息的日常参照，如每张票的差额、观众何时能看、某项奖对应哪类作品，不要求跨条共用一把尺 |

## 本文体反例卡

- 同一新闻拆出两条｜公告与否认并列、计作两条｜合并、逐方归属，缺独立更新就减条。
- 标题先判定、文内才留疑｜首栏还说「可能」，标题已经完成时｜把状态恢复到标题与条目，数字按原口径核。
- 按栏目凑数｜把旧闻搬来填尾栏，或用统一趋势总结所有条｜删无新增条；按窗口重选，以有用的末条或日程结束。
