# 00｜共同文风基座

所有 01–06 文体默认叠加本页。先按「靠什么推进阅读」选文体，再用本页处理标题、证据和不确定性；不可用统一腔调抹平文体差别。

## 写作与编辑

1. **标题给具体抓手。** 写明对象与可辨的动作、摩擦、比较或选择，不用抽象趋势替代正文。可用陈述、问句或轻微反差，不强制问句。标题和副题只承诺正文能找到的东西；「计划」「试图」「可能」以及消息归属不可在压标题时丢失。依据：拆解稿 §七 1–2；[25134](https://www.qdaily.org/articles/25134/)、[64078](https://www.qdaily.org/articles/64078/)。
2. **好奇心式提问从事实生长。** 先给已出现的动作、数字、物件或矛盾，再问它为什么值得看；正文用证据回答，若不能答完就写清已经答到哪一步、剩下什么条件。口语只负责领路，不承担论证。依据：§七 1–2；[50441](https://www.qdaily.org/articles/50441/)、[29393](https://www.qdaily.org/articles/29393/)。
3. **在用到证据的地方写出出处。** 逐项回指引语、数字及事件归属：原文件／采访记录／数据表或已读全文的具名报道，定位到段、条、页、表或时间点；二手转引明确写是谁转述。分别标记者亲见、当事人自述、机构口径、另一方回应和作者推断；图源不等于消息来源。转载、无链或样本口径跳跃不是可继承的写法。依据：§七 3、各卡事实项；[51455](https://www.qdaily.org/articles/51455/)、[55865](https://www.qdaily.org/articles/55865/)。
4. **未确认就留边界。** 把尚未发生、尚待证实、未回复及条件性后果写回对应陈述，必要时也写进标题。出处缺失就补采，仍不足则删掉、缩小断言或按文体标 `BLOCKED`；不得拿标题、摘要或片段替代未取得的关键全文／字幕。数字统计口径不明，不并算；相关不等于因果。依据：§七 2–3、§一验收 3/5、§二验收 2/4、§五验收 3–5；[48837](https://www.qdaily.org/articles/48837/)、[59928](https://www.qdaily.org/articles/59928/)；流程红线见 [07](07-failure-cases.md)。
5. **按阅读目的收尾。** 特稿回到具体处境或未决条件，短讯留后续，汇编让末条完成信息交付，清单让末项有用。没有新增功能就不硬加总结。依据：§七 4；[64055](https://www.qdaily.org/articles/64055/)、[12226](https://www.qdaily.org/articles/12226/)、[64063](https://www.qdaily.org/articles/64063/)、[2545](https://www.qdaily.org/articles/2545/)。

6. **读者入口。** 任何稿件的正文先从普通人能代入的具体人物、具体场景，或与读者日常直接相关的问题切入；文件、数据和制度条文在入口之后再展开，不以文书或报表起笔。题设限定文件型报道时，从材料里找最贴近人的可核事实，例如办事柜台的办理动作、统计数字对应的人及其处境；不虚构人物、动作或亲历。（v3，2026-11-24，据校准案例 1）
7. **术语白话。** 专业术语、制度名词、缩写首次出现时，紧跟一句白话解释：说清它在这里是什么意思、对谁有什么作用或限制，不用另一个术语解释。首次出现若在图说或独立条目，就在那里解释，不让读者翻找。（v3，2026-11-24，据校准案例 1）
8. **切身体会锚点。** 每篇稿子至少两处把主题落到读者自身处境：正在付的钱、正在用的工具、要做的选择，或会撞上的具体时刻。用具体数字、具体动作来写，没有可核数字就写具体动作，不用「用户」「消费者」「人们」这类抽象概括代替。锚点只用材料可支撑的事实与合理情境，不虚构读者经历，不编造数字。材料撑不起某处锚点时，宁可具体写清「这件事暂时不改变你的什么」，也不硬煽。（校准案例 3，2026-11-25）锚点采用什么身份取决于文章的分享目标：可以是读者当下的身份、可能进入的角色（如创业者），也可以不预设身份；关键是让读者把文中的框架、标准或问题套到自己熟悉的事情上，自己做一遍判断、产生自己的想法，不得替读者预设「你不是这类人」。（校准案例 3 补正，2026-11-25）

## 交稿闸门（本项目执行口径，不是原刊规范）

- 先验材料门槛，再成稿。补采期间只报缺口；补不到、且不能在剩余证据下缩题或转型，标 `BLOCKED`，列缺件和受影响的断言。可核的正文与图像可用性分开记。
- 逐项对照 01–06 的八项量表：原七项照旧，第 8 项「读者可理解性」不设事实闸；0 缺失/错误，1 勉强，2 到位；16 分制，≥13 分才过分数线。（v3，2026-11-24，据校准案例 1）表内标「事实闸」的项任一为 0，则整稿不合格。即使错误出现在其他项，只要是关键事实的信源、数字或归属缺失/错误，同步将相应事实项置 0；不得用总分覆盖。无数字或图片且稿件并不依赖它时，按对应量表的条件给分，不强加素材。
- 作者可逐项核稿和附证据，不能替评审填结论；正式终审须与生产模型异构。详见 [07](07-failure-cases.md)。
- 核稿证据与自查备注一律放在稿体之外（回执或文末自查区），不并入正文；正文结尾只承担内容功能，没有新增功能就不另加总结段。（v2 澄清，2026-11-24，据 GT-06 第一轮评审归因）
