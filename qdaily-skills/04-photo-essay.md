# 04｜图说

叠加 [00 共同文风](00-common-style.md)。A 新闻《看图》：画面把读者带进独立新闻；B 单题《10 个图》：接续的图表拆解同一个问题。

## 适用判定

同窗多件更新且画面是进入每条的必要入口，用 A；同题需要多张互不替代的图比较，且能回答一个新闻问题，用 B。多件新事但文字主导转汇编；一件事加无关图转短讯；一项指标已能讲清转数据短报道；纯图、推广和只有通用装饰不适用。同题摄影项目可参考 A1 的方法→人物图文→局限，不套日报栏目。

## 输入材料门槛

- A：新闻拼盘至少两条独立更新（拆解稿的「多条」下限），每条有至少一幅可打开、具实际信息的图及可读新闻出处；第二幅只在另有信息时保留。逐图查人物/对象、时地、作者/供图、资料图性质与授权。旧图只定背景，不证明新事。
- B：一个可核钩子，至少两个分别回答不同子问题的可比较图表单元；有可回查的原表、财报或统计资料，能标时间、范围、来源、单位和必要分母。可据原表制图并署来源，不用图号凑到十。
- 逐张核对可打开且与图说匹配；图区分实际图片、占位、栏花及重复。缺图、署名、授权、说明或源表分别记缺项；补证，或明确降级文字版；不能保持本体裁便 `BLOCKED`，不以相似画面替原照。公开可读不等于可再用。

## 选题指引

A 先公共后果与有场景的更新，次栏可用日常、文化或事件侧面，不必全选轻松题；删同义镜头。B 从反常切入，挑能区分总貌、谁不同及何种解释有证的序列、排行、地图或分组；删重复图和不可并排的口径。

## 结构骨架

- A：提示窗口（普通样本约 3–6% 的文字）→ 主栏（47–63%）→ 有连续素材才插专题 → 次栏（34–47%），最后一个场景即末段。单条＝编号短题→图→署名→图说（定位场景，再给最新进展、影响与新闻出处）；子栏重编号。同事双现场不另计新闻。比例不代表图的版面。
- B：新闻钩子与问题（样本开场约 8–18%）→ 总貌建立基准 → 以地区、群体或时期拆切面 → 比较解释与反例（样本共 4–8 个小节，文字不必等分）→ 在最后一节留给后果/边界，末尾约 5–10% 为编辑起配。每节可用「发现小题→主张→相邻图表→读出差异与限制」；个别节没有合适图可以只用文字。

## 写作手法清单

- 标题｜A 给时间窗或主事件；B 给对象、变化与问题；承诺图数就核实图、重复图、独立图和子面板。
- 开头｜A 快到首个场景，资料图先标旧时间；B 交代异常、统计范围和基准。
- 信源｜A 拍摄者/供图方与谁证实/主张分轨；B 在图及邻文定位原表、时期与口径。
- 视角语气｜A 不把镜头当成全部事实；B 在总体与切面之间切换，相关和因果分开。
- 节奏｜A 图和说明成组，换板块才重编号；B 图跟判断走，邻文解释差异而非复述每个值。
- 结尾｜A 落在事实或动作；B 留边界或下一问，不重做摘要。
- 图说｜照片标时地人物、供图及授权核验；图表标题/轴、单位、分母、时间、范围、来源。关键比较及限制在正文可读，图配可访问文本，不只留在像素里。

## 示例注入

- [55865｜A5 新闻《看图》](https://www.qdaily.org/articles/55865/)：窗口提示 → 旧会议图作入口、正文另写举报和寺方回应 → 计票后冲突／接公共进展 → 南非游行／另一主条 → 旱情／换尺度且救助数据另取出处 → 失窃王室遗物／短条 → 记者与人群对话／末次切镜。原卡验开 6/6 图，不继承其中未独立标署名的做法。
- [63205｜B3 快递](https://www.qdaily.org/articles/63205/)：业绩与件数曲线定总貌 → 消费与低价订单拆需求 → 集中度/议价反查盈利直觉 → 成本、持股与效率分段检验解释 → 配送及运力作对读、落回执行。原卡验开 10/10 图；部分月份收入不与全年柱比绝对量。

## 打分量表

16 分制，≥13 分；第 8 项不设事实闸（v3，2026-11-24，据校准案例 1）。任一事实闸为 0 则整稿不合格。见 00。

| 项 | 0 缺失/错误 | 1 勉强 | 2 到位 |
|---|---|---|---|
| P1 选题与新增 | 纯装饰/导流，或分不出新闻组与单题 | 分型清楚，个别条/图新增不明 | 能一句话指出分型并为每条/图标真正的新信息 |
| P2 标题兑现（事实闸） | 窗口/事件/推断语气错误，或图数将重复、占位算入 | 承诺核对得上，但标题对范围提示不清 | 窗口/事件/确定度准确，若报图数可逐个核独立图/子图 |
| P3 顺序与信息量 | 去图不知顺序，或加图仍无实质信息 | 能复述大致顺序，少数图/文衔接欠明 | 去图能复述证据链，恢复后逐图有独特现场或比较信息 |
| P4 首屏与尾部 | 无首场景/钩子，或空泛硬总结 | 开头或尾部其一可定位，另端泛 | A 迅速见场景并停在末条；B 首段有钩子和问题、末节给边界/下一问 |
| P5 图说与来源（事实闸） | 关键图资料冒现场、无来源/授权，或关键消息/数据归属错 | 主体和主源可核，个别非关键图说或可访问文本不齐 | 照片时地/对象/性质/授权齐，消息另有出处；图表口径、来源及关键文本可读 |
| P6 数据核对（事实闸） | 关键数字没回原表，或误并母体、时间、单位、因果 | 核心比较可重查，次要口径说明欠清 | 可回原表，区分人/人次、率/量、总体/平台、整年/部分期与已发生/预测；无数据对比不硬加 |
| P7 实际交付（事实闸） | 必需图缺/失效/错配，或拿占位和相似图代原图 | 必需图已打开且匹配，逐项核验记录不完备 | 逐图打开、匹配图说并记缺项，成稿所需图均齐；不齐则另交明确标明的文字版，不作为图说完稿 |
| P8 读者可理解性（v3，2026-11-24，据校准案例 1） | 下列三条至多满足一条 | 下列三条满足两条 | ① A 开篇从首图可核的人物或场景切入，B 先用具体人、场景或日常问题提出读图任务，不以文书、报表起笔；② 正文或图说中专业术语、制度名词、缩写首现均紧跟一句不含其他术语的白话解释（无则满足）；③ A 用图说点明画面中的具体动作或可核的日常影响，B 用邻文把关键比较说成每人、每次、常见时段等读者熟悉的尺度，不让读者只靠辨图或读轴推断 |

## 本文体反例卡

- 旧照装当前现场｜照片时间与发稿日不同却不标｜明示资料图日期，现时事件另给新闻出处。
- 硬凑十图｜重复文件、装饰图或同义画面撑数｜逐图写新增，删重复，重核标题承诺；剩单一比较转数据短报道。
- 藏口径于图或想象缺图｜正文不知分母，镜像只显示占位｜回原表并转成可访问文字；图必须补真件或明确转文字稿。
