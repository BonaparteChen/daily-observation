## GT-01｜从释宪命令到户政柜台：台湾同婚登记第一天｜文件型长报道

订单：以 2019-05-24 为截点，回答权利如何由解释变成可以办理的登记，以及首日统计能证明什么。只写文件型报道，不模拟现场。

固定材料包：
1. [伴侣盟转载司法院释字第 748 号解释（含全文）](https://tapcpr.org/main-topics/marriage-equality/story/chi-chia-wei/2017/05/24/20170524)：解釋文、理由和事实摘要分栏；此为法院文本的公开转载，不把伴侣盟当裁决方。
2. [总统府第 7425 号公报 PDF](https://www.president.gov.tw/File/Doc/8c29ebe8-d330-40c0-90db-f246649e6384)：2019 年公布版，重点第 2、4、27 条。
3. [行政院网站所载内政部户政司首日统计 PDF](https://gec.ey.gov.tw/File/42D65FBB9BE769A7?A=C)：2019-05-24，按县市，单位为对。

必验（[01](01-long-form.md)）：L1/L2 从一个可定位的文件差异或登记结果开头；L3/L4 用解释的两年期限和逾期条件、公布版的登记方式及施行日、首日实办记录依次推进；L5 正确标出全体 526 对、统计期为一日，若举县市必须回其表格行；L6 明说首日统计不能回答的一项实施问题。

已知陷阱：2017 解释公布、2019 法律公布及施行不是一日；逾期安排不是已走过的程序；首日登记不是预约、人数或需求总量。不得把后续修法倒灌、表格写成记者亲见。

## GT-02｜《大象席地而坐》在柏林电影节论坛单元放映｜短资讯

订单：以 2018-02-20 为截点，只报该片在论坛单元的放映，给读者作品与这次放映的具体背景，不写影评。

固定材料包：
1. [承办方 Arsenal 的 2018 论坛单元影片档案](https://www.arsenal-berlin.de/en/berlinale-forum/archive/program-archive/2018/forum-program/main-program/an-elephant-sitting-still-1/)：片名、胡波、论坛节目与 230 分钟片长。
2. [好奇心日报当时报道／镜像 50419](https://www.qdaily.org/articles/50419/)：2 月 16 日在电影节放映的具名二手报道；仅取已核报道范围，不以其为制片争议或传言背书。

必验（[02](02-short-news.md)）：S1/S3 首屏给单一动作、2 月 16 日和单元范围；S2/S4 标题不超出论坛单元放映，具体日期注明报道归属，节目和时长回档案；S5/S6 用与本次放映直接相关的版本/片长或具体资料作解释和尾，不跑去写第二则戏剧性新闻。S7 无必要不转载剧照。

已知陷阱：论坛展映不是柏林主竞赛获奖，也不是内地公映；2 月 20 日是报道截点不是放映日。把片长写成所有发行版本的通用长度、把评论和制片方面传言写成经证实事实，均错。

## GT-03｜这个周末的电影消息：戛纳赛果与降旗康男讣告｜娱乐资讯汇编

订单：2019-05-25 至 05-27（各来源当地报道日）的周末补辑，只做这两条独立新闻；一条焦点、一条较短的讣告。以当期信息为限。

固定材料包：
1. [戛纳电影节 2019-05-25 官方奖项名单](https://www.festival-cannes.com/en/press/press-releases/all-the-72nd-festival-de-cannes-awards/)：依竞赛类别核奖项、作品与人。
2. [日本经济新闻 2019-05-26 讣告](https://www.nikkei.com/article/DGXMZO45291650W9A520C1CZ8000/)：死亡日期、年龄及作品背景。
3. [Daily Sports 2019-05-27 的报道和木村大作采访](https://www.daily.co.jp/gossip/2019/05/27/0012369494.shtml)：同一事件补充材料，不另算第三条；若援引评论请具名。

必验（[03](03-digest.md)）：D1/D3 首屏明示补辑时间窗，焦点和讣告是两件事；D2 两个标题点都可定位；D4/D5 每条能独读，奖项回官方名单，讣告注明日媒并区分 5 月 20 日去世与周末消息公开；D6 赛果详于讣告，停在有用的末条，不用行业趋势统摄。

已知陷阱：把戛纳同一主竞赛的几个奖机械拆成几条独立更新；把颁奖日写成去世日，或把讣告两个来源算作两件事；混淆主竞赛金棕榈与短片奖。

## GT-04｜2019 年快递件数涨了，增长来自哪里？｜单题图说

订单：以公报发布日 2020-05-19 为截点，用三幅独立自制图表依序说明全国总貌、业务类型、地区差异。用给定原始公报重绘；现有插图不是必用素材。

固定材料包：[国家邮政局《2019 年邮政行业发展统计公报》](https://www.spb.gov.cn/gjyzj/c100015/c100016/202005/3b737880d332463bb63e027d70fd4476.shtml)。取「一、业务发展情况（二）快递业务」中的全国业务量与同比、同城/异地/国际港澳台的业务量与同比、东中西部件数/份额/同比；同时读文末备注的地域与四舍五入口径。这是同一原公报中的三个不同切面。

必验（[04](04-photo-essay.md)）：P1/P3/P4 用发布钩子提问，三图分别回答总貌/类别变化/地区对比，去图仍能读出顺序；P2 如标题报数须为 3 个独立图；P5/P6 每图标年份、范围、指标单位、必要分母和出处，正文写出异地增长与同城下降的区别及一项地区对照；P7 三幅实图逐一可打开、贴对应文字，另附可访问文字；收在统计可见的业务结构，不替行业判因果。

已知陷阱：邮政业务总量、快递件数、业务收入不是一回事；异地占比不等于同比；公报不含港澳台本地统计并不等于没有国际/港澳台业务分类；四舍五入的分项不强凑总额，公开原图也不等于获许可。

## GT-05｜2018 年民航死亡人数和事故率，讲的是同一件事吗？｜数据短报道

订单：以 ICAO 2019 版报告为历史截点，比 2017 与 2018，不借后来修订版改值。不做多图解说。

固定材料包：[ICAO《State of Global Aviation Safety》2019 版 PDF](https://www.icao.int/sites/default/files/sp-files/safety/Documents/ICAO_SR_2019_final_web.pdf)，Executive Summary、Chart 1–2 与 Accident Statistics：分开事故率、事故数、致命事故和死亡数。

必验（[05](05-data-story.md)）：N1/N2 用报告发布切入，首屏明确全球定期商业运行、报告所纳入航空器重量和每百万离港架次口径；N3 同版同口径比较 2017 与 2018，标 2017 为低基线；N4 按原图/原表核 50 与 514 人、每百万离港架次 2.4 与 2.6 起并交代是报告值，不将舍入数自算为精确变化；N5/N7 不凭一年差异断长期趋势、单航班风险或事故原因；N6 如制图，应与同一口径正文对读。

已知陷阱：伤亡人数不是事故率；致命事故数不是死亡人数或全部事故数；不同版、其他组织或原样本的 60% 都不是本题数据。

## GT-06｜读贝索斯 2017 年度股东信，先看这五项业务披露｜清单

订单：以 Amazon 发信日 2018-04-18 为截点，从同一份信中挑五项业务披露给只想抓经营变化的读者。不是排名；五项须同一筛法，不必正好复刻样本的五个对象。

固定材料包：[Amazon 官方 2017 Letter to Shareholders 全文](https://www.aboutamazon.com/news/company-news/2017-letter-to-shareholders)，候选池限定在本信 Recent Milestones，不把附录重刊的 1997 股东信纳入。只取正文，图片不必转载。

必验（[06](06-list.md)）：C1/C2 开头写明读者、候选池与筛选标准，标题及正文兑现五项、非排名；C3/C4 各项有名称及统一字段（本题用业务、公司披露、为何值得看/不能说明什么），每项可独读并回定位段；C5 区分公司披露与编辑选择，若用 AWS run rate、Prime 全球付费会员等需保持单位、时期与范围；C6 最后一项给可用提醒或阅读定位，不添空话。C7 无必要图时不硬加。

已知陷阱：把 AWS run rate 当全年收入；把付费会员规模称为当年新增或美国数；把股东信自述写成独立审计或把重刊 1997 内容当新披露。
