# 06｜清单

叠加 [00 共同文风](00-common-style.md)。先交一把比较尺，再让每项各自可用。

## 适用判定

适合在共同场景、候选池或观察维度下挑出多个对象，例如院线怎么选、怎样走设计线路、初公布片单哪些值得留意、一份披露有哪些值得读。外部榜可解读，但榜不变成编辑评分；无名次不写排名。同一日多件新闻转汇编；单条更新转短讯；图负责推进论证则转图说，不凭标签或标题数字分型。

## 输入材料门槛

- 一份可定位的候选池或名单及其时间/范围，和一个共享纳入标准；至少两项可独立使用的对象。每项至少有可核名称、同题固定字段、独有观察或材料证据各一处，足以支持推荐/避雷/预期。标题若承诺 N，开工时就要有 N 项满足门槛。
- 核亲看与否、候选/正式入选/排名、官方预告/外部评价等状态；用外榜需确认样本、时间、指标；地点、日期、版本、格式、可及性按题核。图非必要；若用核原图、来源、版本和性质。
- 缺字段/实据先补采；删缺证项并重核标题，或按实际材料转型；剩不足两项或无法兑现固定订单则 `BLOCKED`，不以通稿或想象补齐。

## 选题指引

挑能给读者同一把尺而又各有不同的选项。可用推荐优先、参观路线、比较强弱或原榜规则排序，但全篇用一个主原则；不能各凭广告语入选或把平台热度当总体。

## 结构骨架

1. 标题写范围＋数量、首推或相对判断；导语一两段写谁用、何时何地、候选池与这回合筛法/亲看状态。
2. 逐项段群：名称→对象类别/固定字段→一项独有证据或观察→条件、适用人群、位置/日程或局限。条目单独读得懂，不要求等长。
3. 末项直接给指引；只有共同限制值得说明时才另加短尾。

文字起配参照样本：导览/材料型开头约 19–20%（如 29889、52317、60451），其余给条目；两片深比可用一句总览约 1%，两条各近一半。不是篇幅配额。

## 写作手法清单

- 标题｜兑现数量与选择结论；把「首批」「预期」写成相应状态，不包装成正式榜。
- 开头｜定候选边界与筛法；没亲看说明材料是片单/预告/评价。
- 信源｜编辑观察、外部榜单、媒体评价、主办方、企业披露分别归属；榜给样本、时间、指标和外推限制。
- 视角语气｜可有偏好，但用具体可指认的观察、例子或材料支持，不复述剧情当推荐。
- 节奏｜名称与固定字段利于跳读；逐项给不同的信息，不硬套等长段数或强制转折。
- 结尾｜在最后一项给提醒、去处、可查链接、限制或下一步，无用总结删掉。
- 图说｜剧照/建筑照片贴对应项，分剧照/预告、效果图/实地；图不证明质量，缺图不猜。

## 示例注入

- [2545｜北京国际设计周](https://www.qdaily.org/articles/2545/)：导语给大型活动池与七项选择 → 79 罐／地标进题 → 巴塞罗那在大栅栏／城市合作 → 设计猫／展品入口 → 椅展／主题定位 → 城市设计／换尺度 → CCD／线路上的独立项 → 设计影像／用日期和入口完成导航；时地可由明确链接补字段，不凭标题有人数就当清单。
- [52317｜贝索斯股东信](https://www.qdaily.org/articles/52317/)：开场分旧故事和新披露（约 19%）→ Prime／会员与范围 → AWS／业务指标 → Alexa／生态规模 → 全食／经营动作及定性披露 → 全球投资／回看投入逻辑。五条约各占 12–25%；是企业自述的编辑挑读，不是独立数据排名。

## 打分量表

16 分制，≥13 分；第 8 项不设事实闸（v3，2026-11-24，据校准案例 1）。任一事实闸为 0 则整稿不合格。见 00。

| 项 | 0 缺失/错误 | 1 勉强 | 2 到位 |
|---|---|---|---|
| C1 共同筛法 | 没有共同场景/标准，或把独立新闻拼成榜 | 有场景和池，部分入选理由不明 | 一句话说出给谁、何种场景、比较什么，逐项符合纳入标准 |
| C2 数量与状态（事实闸） | 承诺 N 却不符，或把未看/候选改成看过/入选 | 数量和状态正确，但导语提示不够清晰 | 承诺的 N 逐项可数，可看/预测、候选/正式/排名均明确 |
| C3 跳读字段 | 条目名或固定字段基本缺失/各项内容可互换 | 多数能单读，个别少字段或独有观察 | 每项有醒目名、统一必需字段和至少一项独有信息 |
| C4 具体理由 | 拿宣传、剧情或漂亮图替代判断 | 多数有证据，个别判断泛 | 每项的推荐/避雷/预期至少有一条可指认证据 |
| C5 信源与指标（事实闸） | 把外部口径写成独立评估，或关键数据/归属无据 | 核心可核，次要样本边界交代不足 | 观察、企业/主办方、评价/数据分轨；榜单注明时间、样本、指标及外推限制 |
| C6 决策信息（事实闸） | 关键时地、可及性、版本等错误或无从核对 | 主决策信息可核，末尾略重复或次要字段不全 | 按题可核地点、时段、格式和可及性；末项有用途，无空总结 |
| C7 配图归属（事实闸） | 关键图不可核、错项、错认图型或来源 | 图可核但摆位/说明欠清 | 图贴本项且来源版本明确，不以旧图补想象；无必要图可纯文本 |
| C8 读者可理解性（v3，2026-11-24，据校准案例 1） | 下列三条至多满足一条 | 下列三条满足两条 | ① 导语先给一个具体使用、选择或阅读场景，或读者要作的决定，再介绍候选池和筛法，不以名单、文书或报表起笔；② 各项独读时，专业术语、制度名词、缩写首现均紧跟一句不含其他术语的白话解释（无则满足）；③ 每项把关键数字或信息落到可比较的日常尺度，如单次费用、步行多久、在哪种情况下用得上，或业务指标对日常使用意味着什么，不硬造名次或数字 |

## 本文体反例卡

- 外部榜变编辑榜｜入选和排名说得像编辑亲评，或把平台榜当全国｜恢复发布方、样本和指标，只在范围内解释。
- 说了 N 却扫不出 N 项｜角色、剧情或素材重复算成项，字段散落｜重数对象，统一字段，按实数改标题。
- 预告当观后感｜未看片却断言成片表演/风格｜标未看与预告/片单出处，只写可证的观察或预期。
