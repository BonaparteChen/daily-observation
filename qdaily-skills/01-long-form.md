# 01｜长报道／特稿

叠加 [00 共同文风](00-common-style.md)。推进单位：下一组证据改变对同一个问题的理解。

## 适用判定

适用于有变化过程、可对照机制或可展开争论的现场、文件型长稿，以及有真追问的访谈、有独立论点的书评。单一新事转短讯；只有单向口径则缩成带归属的解释；只有书摘转导读，画面才是主轴转图说。精彩但无从核实的场景不能开稿。

## 输入材料门槛

- 报道：一个可定位的当下切口，加至少两类相互独立、能对核心断言施压的材料（如原文件与当事人采访／现场笔记，或制度文本与独立实施记录）。同一口径被转发不算第二类。场景有时地、人物行动与出处；无亲见则按文件或明确归属的回忆写。涉及需回应的指控保留联系结果。
- 访谈：可回听/重查的完整核心问答，至少有可指认的实质追问、未决条件，以及可对读的文本或材料。不按受访者人数核门槛。书评：原书版本和至少两处可核页码，区分原书论证与书评异议。
- 必需图片验原件、作者/机构、时地对象、权属及敏感人物的同意与再识别风险。不足先补采；可用剩余证据缩小断言或转稿型则重过门槛，否则 `BLOCKED`。

## 选题指引

挑能跟踪的新旧处境、同流程两地差异、机构说法与实际结果的冲突，或可用具体物件呈现代价的问题。避免把发布会、展讯、纯推广、长背景或无评价的书摘拉长。

## 结构骨架

1. 约 15%｜读者入口段（第一段，可接一组短段）：直入式先给可核的具体人物、场景或日常问题，再交代为何此刻；物件、核准原话可帮助呈现入口，文件型稿从文件中最贴近人的事实落地，之后再展开文书、数据或条文。L1 仍按原判据核首屏的对象、主问、当下性及标题承诺，L8 另核普通读者能否从入口进入，不替代 L1。（v3，2026-11-24，据校准案例 1）也可采用缩放式：以时代、行业或文明尺度的问题开局，延展到它对人类文明的意义，再把镜头缩放到与个人命运的联系；详见下文「镜头缩放」。两条路径均按 L1 原判据核首屏。（校准案例 3 补正二，2026-11-25）
2. 约 25%｜铺第一组证据：从动作或文本还原过程，给相关者所知。
3. 约 30%｜换现场、角色或口径：先给足前一方，再上能修正答案的对照；需要时插有时间锚的前史。
4. 约 20%｜解释机制与代价：谁决定、谁承担、哪些关系还不能证明。
5. 约 10%｜回到起点的新处境，或用可追查的未决事项收束。

比例是编辑起配而非硬模板。Q&A 用逐层追问替代换场；书评可先交代作者的方法，再用细读给出异议；倒叙须回答前面留下的具体问题。

## 写作手法清单

- 标题｜对象＋具体摩擦或变化；如写「我们去了」，正文得有亲见可以回指。
- 开头｜直入式先写可核的人、场景或日常问题，尽快定位人、物、时地；文件稿先写可核的办事动作或处境变化，再标文件和时间差，不以公文起笔、不补无证现场，也不先写对象全史。（v3，2026-11-24，据校准案例 1）长文也可用下条「镜头缩放」的方式开头。（校准案例 3 补正二，2026-11-25）
- 镜头缩放｜宏大开局给分量，缩放落点给体感。从时代、行业或文明尺度的问题开局，延展到它对人类文明的意义，再用证据写清这个大问题如何影响具体的人、他们要做的具体选择和要承担的具体代价。最终必须落到材料可支撑的具体个人处境，不能停在口号。（校准案例 3 补正二，2026-11-25）
- 解释｜专业术语、制度名词和缩写首现后紧跟一句白话，说明谁能做什么、谁受限或实际发生了什么；不用另一术语顶替解释。（v3，2026-11-24，据校准案例 1）
- 信源｜亲见、回忆、利益方、文件、转述、推断逐一分轨；场景和引语回原始记录。
- 视角语气｜跟着能接触证据的人；换镜头必须带来新知识，不借有限观察替群体发言。
- 节奏｜动作→解释→新证据，背景只在问题需要时出现。
- 结尾｜人物行动、新处境或具名未决条件；不补空泛判断。
- 图说｜只用能定位、比照、留证或具象化的图；交代时地、对象、来源和局限，效果图不可作实景。

## 示例注入

- [10513｜无人超市](https://www.qdaily.org/articles/10513/)：01–05 用付款经验引出一日活动／限定假设 → 06–15 两店选址和客群／设比较 → 16–28 写购物阻滞和店员干预／打断原假设 → 29–36 对照实收与未公开数据／限定能说什么 → 37–44 回看支付背景和准入资格／反查活动命名。不把两地当总体实验；图占位不补画面。
- [51455｜B 站招股书](https://www.qdaily.org/articles/51455/)：01–09 文件时间差／钉住上市前的矛盾 → 10–18 收入依赖／引监管约束 → 19–27 平台自审与风险披露／对读口径 → 28–44 从用户增长转向受众约束／翻转公司叙事 → 45–53 用从业者撤片收束／呈现当时反应，不预言上市结局。段号为拆解稿阅读块，不是原站段号。

## 打分量表

16 分制，≥13 分；第 8 项不设事实闸（v3，2026-11-24，据校准案例 1）。任一事实闸为 0 则整稿不合格。标记与扣分联动见 00。

| 项（沿用拆解原序） | 0 缺失/错误 | 1 勉强 | 2 到位 |
|---|---|---|---|
| L1 主问与承诺 | 无主问或标题越过正文 | 对象明确，缺当下性或反差不具体 | 首屏可说出对象、主问与当下性；标题每项承诺均有正文位置 |
| L2 场景/文件锚（事实闸） | 关键场景不可追溯或回忆冒作亲见 | 核心来源可找，个别时地或动作定位缺 | 场景有时地、动作和来源类型，可回记录；无场景稿能定位文件/文本与时间 |
| L3 核心证据链（事实闸） | 断言无出处、误挂，或报道仅一路口径硬撑 | 有可核对读，但非核心的来源层次或联系结果交代不清 | 报道有两类独立材料及所需联系结果；访谈有实质追问和未决，书评有至少两处可核版本页码与异议分轨 |
| L4 段落增量 | 板块重复或时间线断裂 | 主序可跟，少数板块无新增或缺过桥 | 审稿能逐块标职责、实际占比和新证据；倒叙有锚点，现场转制度有证据过桥 |
| L5 关键数字/推断（事实闸） | 核心数错口径/无出处，或把相关、预测当事实 | 数可回查，但次要时间、单位或范围欠明 | 核心数的来源、时期、单位/分母明确；比较范围、条件与推断分清，无数字不强加 |
| L6 结尾回扣 | 只有拔高、总结或无据场景 | 回到同题但没给新处境或边界 | 最后实质段能指出动作、处境变化或具名条件，回应开篇 |
| L7 图文各自可核（事实闸） | 必需图缺/不可核，图型或署名造假，或敏感识别风险未核 | 图可核且权属明，次要图说位置或说明欠清 | 必需图逐项核权属、时地、对象、来源及用途；无必需图则正文独立，不用缺图撑断言 |

## 本文体反例卡

- 背景长不等于长稿｜相邻两块只能复述同一句结论｜合并，补能改变答案的第二类证据；补不到则缩题。
- 记者视角冒充亲见｜开头有精确场景却只来自受访者回忆或企业供图｜恢复归属和时地，改文件开头或删无证细节。
- 数字并排冒充可比｜把无人超市少付款与行业偷盗率直接比较｜查原口径、分母与期间；不等口径分别报，不据此下效果结论。
